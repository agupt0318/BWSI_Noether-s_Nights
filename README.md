# BWSI Noether's Nights

Implementation work based on the paper linked below, developed for BWSI.

Paper: [arXiv:2205.03529](https://arxiv.org/pdf/2205.03529)

## Overview

This repository contains an educational/research implementation using quantum-computing and graph-related Python libraries.

## Dependencies

The project uses:

- Qiskit
- Qiskit Aer
- Matplotlib
- NumPy
- NetworkX
- rustworkx

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Status

Course/research prototype. Future cleanup would include adding a clear entry point, example outputs, and a short explanation of which parts of the paper are implemented.
